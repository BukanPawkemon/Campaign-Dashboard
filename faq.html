Frequently Asked Questions

About Dalang

Short answers to the questions that come up most often about what Dalang is, how it plays, and where your data lives. The guide pages cover each feature in depth, and How Dalang Compares looks at the other tools in this space.

What Dalang is

What is Dalang?

Dalang is a campaign management tool for Dungeon Masters running a Dungeons & Dragons game. It holds the world and house rules, a location hierarchy with encounters and treasure, an NPC roster, and a job board, then helps you run the session with a live battle map and hand players a read-only link that shows the current scene. It keeps a permanent event log of what happened afterward.

It comes two ways: a free Windows desktop app, and a browser app at dalang.page. A campaign moves between them freely.

Is Dalang a virtual tabletop (VTT)?

Not in the full sense. Dalang is primarily a prep and session-running tool. It does include a live battle map with grid calibration, tokens, initiative order, fog of war, a ruler, pings, and freehand drawing, which is enough to run a fight.

It does not have dynamic lighting, automated character sheets, a rules engine that resolves attacks for you, built-in voice or video, or an asset marketplace. If you want a heavy tactical VTT, Foundry VTT or Roll20 fit better. If you want organised prep plus a simple map and a zero-setup player view, that is what Dalang is for. See the full comparison.

Does Dalang work for play-by-post or asynchronous campaigns?

Yes. The prep tools, the event log, and the Player Guide export do not assume everyone is online at once. The live battle map and the shared player link are built for a real-time session, in person or on a call, but they are optional. Plenty of DMs use Dalang purely as a prep organiser for a game they run over text.

Can I use Dalang to run a game over Discord or Telegram?

Yes. Dalang does not host chat or voice itself. You run the conversation wherever your group already talks, and use Dalang for prep, the event log, and, when you want it, the shared player link. The link is a plain URL you paste into your group's channel; players open it in a browser with no sign-in.

Running it

Does Dalang need an internet connection?

Dalang Desktop does not. It stores everything in a local file on your machine and makes no network calls, so it works fully offline. Dalang Web runs in the browser and needs a connection, since your campaigns are saved to your account on a server.

Is there a Mac or Linux version?

The desktop app is built for Windows. On macOS or Linux, use Dalang Web in a browser instead: it has the same tabs and tools. A native Mac or Linux build is not available today.

Is Dalang really free?

Yes. Dalang Desktop is free and pay-what-you-want on itch.io, including nothing. Dalang Web is free while it is in public beta, with every feature included and generous per-account limits.

Paid plans with higher limits are planned for after the beta, but the desktop app stays free and the core of the web product will not be put behind a paywall. See the free plan details.

What edition of D&D does Dalang support, and can I use it for other systems?

The built-in compendium covers the D&D System Reference Document, both the 5.1 (2014) and 5.2 (2024) releases, and you can add homebrew monsters, magic items, and equipment.

Everything else, the world, house rules, locations, NPCs, jobs, and the event log, is free text, so DMs do use Dalang for other d20 games and lighter systems. There is no rules automation tied to a specific system.

Does Dalang use AI to write my campaign?

No. Dalang does not generate world lore, NPCs, plot, or narration for you. It is a tool for organising the campaign you write yourself, and the aim is for it to stay a straightforward, human-driven prep and session tool.

Players and sharing

Do my players need to install anything or make an account?

No. Players open one read-only link in any browser, with no sign-in and nothing to install. Only the DM needs the app or a Dalang Web account.

What can players see through the shared link, and what stays hidden?

The link shows the current location, the active jobs, which NPCs are present, and during a fight the battle map, dice rolls, and the pings and drawings you make. It never shows your DM notes, plot secrets, encounter details, treasure, unrevealed map areas, or hidden tokens. You control what is visible by what you set as the current scene. See The Player Window.

Does Dalang come with published adventures like Dragon of Icespire Peak?

No. Dalang does not bundle commercial adventures. You build your own campaign, save a finished one to your Library to start future campaigns from, or import a campaign file another DM shares with you. The compendium ships with the free SRD rules content only.

Can I import characters from D&D Beyond?

Dalang Desktop can pull a character from a public D&D Beyond sheet into the Players tab. This is a desktop-only feature for now. On Dalang Web you can still paste the sheet link to keep it handy.

Your data

Where is my campaign data stored, and can I get it out?

Dalang Desktop keeps each campaign in a JSON file on your own machine. Dalang Web keeps campaigns on your account on a server, hosted in Singapore. Either way you can export a whole campaign to a single file at any time from Campaign Settings, and that file opens in either version. Your content is yours: Dalang provides the tool, not the content.

Can I move a campaign between Dalang Desktop and Dalang Web?

Yes, in both directions. Export a full campaign from Campaign Settings and open the file in the other version. Locations, NPCs, jobs, players, the event log, and any homebrew used all carry across.

Update Dalang Desktop to version 1.3.0 or later before moving a campaign to the web; that is the tested path. Images added from a file on your own computer do not transfer, because Dalang Web uses hosted image links only. See Bringing a campaign from Dalang Desktop.

Who makes Dalang?

Dalang is made by one independent developer and started as a personal tool for running an async D&D game with friends. It is not affiliated with or endorsed by Wizards of the Coast. See Philosophy and Background for the longer story, and Legal & Sources for licensing and attribution.

Dalang Web runs all of this from a browser, free during the beta, with a live read-only link for your players.
