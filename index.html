Dalang - Campaign Dashboard, formerly just Campaign Dashboard, is a desktop app for prepping and running a D&D campaign: writing the world and house rules, prepping locations and NPCs and jobs, running the actual session with a live battle map, and keeping a permanent record of what happened afterward.

Everything is stored in a local file on your machine, not in the cloud, so your notes and any NPC secrets stay private. It works for async play / Play by Post just as well as sitting at a real table or on a call, the live-session tools like the battle map and the Player Window are built specifically for that in-person side.

What's new

v1.2.0

New features

  • Added a Player Guide export, a standalone HTML or PDF file for your players, DM-curated: pick exactly which Story sections, Locations, NPCs, and Quests to include, preview it live, then export one file, no app install needed to read it. See Player Guide.
  • Maps can now be printed at true physical scale, 1 grid square = 1 inch, straight from the calibration you already did. Pick a paper size, position the page overlay, export a ready-to-print PDF. See Setting Up a Map.
  • Added 2024 SRD content for Monsters, Spells, Conditions, and Weapon Properties, shown alongside the existing 2014 data with a filter to pick an edition. Equipment, Magic Items, and the rest of the reference are still 2014 only for now. See SRD 2014 vs. 2024.

Improvements & fixes

  • Popups no longer close if you start a text selection inside one and release the mouse outside it.
  • The main window can no longer be resized down to a broken, unusably small size.

v1.1.0

New features

  • Every image field, NPC and Player portraits, Location images, the Campaign card, the DM background, can now Browse to a file on your own computer instead of only pasting a URL. (It's a desktop app. Of course it can read a file off your own disk. Silly me.) See Campaign Prep.
  • Monster portraits can now be fixed directly from the Battle Map mid-encounter, no more detouring through Compendium just to set a picture. See Running a Live Session.

Improvements & fixes

  • Fixed the Player Window's dice roll banner not animating on a fresh roll, and blending into busy map backgrounds.
  • The Player Window now has its own distinct title, fixing tools like OBS showing two identical, indistinguishable windows.
  • Fixed the sidebar's tab list getting clipped on a short window, with no way to scroll to tabs past the bottom.
  • Every native file picker now shows the Dalang icon instead of the generic one.
