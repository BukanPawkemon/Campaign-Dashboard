Dalang - Campaign Dashboard is a tool for prepping and running a D&D campaign: writing the world and house rules, prepping locations and NPCs and jobs, running the actual session with a live battle map, and keeping a permanent record of what happened afterward. The live-session tools, the battle map and the Player Window, are built for playing in person or on a call, and it works just as well for async play / Play by Post. It comes two ways, and a campaign moves between them freely:

Dalang Desktop

An app for Windows. Everything is stored in a local file on your machine, not in the cloud, so your notes and NPC secrets stay private and it works with no internet at all.

Dalang Web public beta

The same app in a browser, nothing to install. Campaigns live in a free account you can open from any computer. See Using Dalang Web.

What's new

v1.3.0

New features

  • Dalang Web, a browser version of Dalang at dalang.page, now in public beta. Make a free account and your campaigns sync to it, so you can prep from any computer and run a session without installing anything. Dalang Desktop is unchanged and still works fully offline. See Using Dalang Web.
  • Player Window position lock, a lock toggle on the Live Run map toolbar. Lock it and the Player Window holds its current view while you pan and zoom your own screen, so tokens on a table monitor stay lined up. Separate from Pause. See The Player Window.
  • Player Window fullscreen, a toggle on the Player Window itself (F11 to toggle, Esc to exit). Hides the title bar and taskbar so the map fills a table monitor.
  • A "From a File" starting point in the New Campaign box, next to Fresh Adventure and From Your Library. It takes an adventure file or a full campaign file and always adds a new campaign. Importing used to be buried on the Library screen.

Improvements & fixes

  • Mouse-wheel map zoom now moves in small steps instead of jumping by roughly half again each notch, and the zoom percentage is a field you can type an exact number into. Applies to the battle map and grid calibration.
  • One Export Campaign button replaces the separate "Move to Dalang Desktop" and "Move to Dalang Web" ones, they wrote the same file either way. It opens a chooser for Adventure or Full Campaign.
  • The campaign's card image now travels with a Full Campaign export and import.
  • Revealing or hiding fog of war on the Player Window now fades over about half a second instead of snapping.
  • Guide and Feedback links moved from the top bar into the sidebar, each with a small arrow marking that it opens a browser tab.
  • Print mode is reachable straight from grid calibration now, no Save & Close and reopen first.
  • Image URL fields fall back to the placeholder icon when a URL doesn't load, instead of a blank box.
  • App fonts are bundled with the app instead of loaded from Google's font CDN, no network call to Google at startup.

v1.2.0

New features

  • Print your map for an offline session, no laptop needed at the table. Maps now export at true physical scale, 1 grid square = 1 inch, straight from the calibration you already did. Pick a paper size, position the page overlay, export a ready-to-print PDF. See Setting Up a Map.
  • Share your campaign prep with your players, so they show up ready. The new Player Guide export builds a standalone HTML or PDF file, DM-curated: pick exactly which Story sections, Locations, NPCs, and Quests to include, preview it live, then export one file, no app install needed to read it. See Player Guide.
  • Added 2024 SRD content for Monsters, Spells, Conditions, and Weapon Properties, shown alongside the existing 2014 data with a filter to pick an edition. Equipment, Magic Items, and the rest of the reference are still 2014 only for now. See SRD 2014 vs. 2024.

Improvements & fixes

  • Popups no longer close if you start a text selection inside one and release the mouse outside it.
  • The main window can no longer be resized down to a broken, unusably small size.
