# Dalang - Campaign Dashboard, User Guide

Dalang, formerly Campaign Dashboard, is a desktop app for prepping and running a D&D campaign: writing the world and house rules, prepping locations and NPCs and jobs, running the actual session with a live battle map, and keeping a permanent record of what happened afterward.

Everything is stored in a local file on your machine, not in the cloud, so your notes and any NPC secrets stay private.

Published via GitHub Pages at https://bukanpawkemon.github.io/Campaign-Dashboard/. The guide is a static, no-build-step multi-page site: `index.html` is the landing page, one `.html` file per feature (`npc.html`, `dice-roller.html`, and so on), a shared stylesheet at `assets/style.css`, and shared nav/footer markup at `assets/nav.js` (two small custom elements, `<site-nav>`/`<site-footer>`, so the same chrome doesn't have to be hand-copied into every page). Screenshots live in `screenshots/`, pulled from a throwaway demo campaign (Guild Founding), not real campaign content.
